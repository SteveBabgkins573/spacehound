# 🦫 SpaceHound

> ⚠️ **Только для Linux.** Программа сделана и протестирована на Pop!_OS / Ubuntu / Debian.
> На Windows и macOS не запускается.

Быстрый поиск больших файлов на чистом Rust. Сканирует диск **параллельно во все ядра**,
показывает топ файлов по размеру, статистику по расширениям, помечает подозрительные
(временные файлы, дубликаты, установщики) и предлагает переместить их в резервную копию.
**Ничего не удаляется без вашего подтверждения.**

## Возможности

- ⚡ Параллельное сканирование через `std::thread` — использует все доступные ядра
- 🔍 Фильтры по минимальному размеру (`--min`) и расширению (`--ext`)
- 📊 Статистика по расширениям и суммарному размеру
- 📄 Экспорт отчёта в текстовый файл (`--export`)
- 🦜 Нет — анимаций больше нет, только результат
- 🛡 Бэкап вместо удаления (`~/.spacehound-backup`), дубликаты не перезаписываются
- 🔢 Ровно 4 попытки, затем сообщение о завершении
- 🌍 Русский / English
- 🔙 Кнопка «вернуться» — начать сначала

## Сборка и запуск

```bash
cargo build --release
./target/release/spacehound
```

Или интерактивно:

```bash
spacehound
spacehound ПУТЬ -n 15
spacehound ПУТЬ --min 100M
spacehound ПУТЬ --ext mp4 -n 10
spacehound ПУТЬ --export /tmp/report.txt
spacehound ПУТЬ --ru
```

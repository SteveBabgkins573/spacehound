# 🦫 SpaceHound

> ⚠️ **Только для Linux.** Программа сделана и протестирована на Pop!_OS / Ubuntu / Debian.
> На Windows и macOS не запускается.

Умный поиск больших файлов на Rust. Сканирует диск, показывает топ файлов по размеру,
помечает подозрительные (временные файлы, дубликаты, установщики) и предлагает
переместить их в резервную копию — **ничего не удаляется без вашего подтверждения**.

## Возможности

- 🎉 Приветствие и выбор языка (Русский / English)
- 🦜 ASCII-анимации (попугай, бегущий человечек, двигающаяся рука)
- 🔄 Ровно 4 попытки сканирования, затем сообщение о завершении
- 🔍 Рекурсивное сканирование с сортировкой по размеру
- ⚠️ Умные рекомендации по удалению
- 🛡 Бэкап вместо удаления (`~/.spacehound-backup`)
- 🔙 Кнопка «вернуться» — начать сначала

## Сборка и запуск

```bash
cargo build --release
./target/release/spacehound
```

Или интерактивно:

```bash
spacehound              # приветствие → язык → анимация → путь
spacehound ПУТЬ -n 10   # быстрый режим
spacehound ПУТЬ --ru    # русский вывод
```

## Что исправлено в 0.6 (deep audit)

- 🐛 Безопасный срез UTF-8 в именах файлов (раньше русские имена/эмодзи могли вызвать panic)
- 🐛 Анимация respect'ит выбор «без анимации» (раньше попугай крутился всегда)
- 🐛 Бэкап не перезаписывает дубликаты — добавляется суффикс `_1`, `_2`
- 🐛 Кнопка «вернуться» сбрасывает счётчик попыток
- 🐛 Двойной слеш в выводе «Попытка 1 //4» → «1/4»

Сделано с ❤️ на чистом Rust (std only, без внешних зависимостей).
